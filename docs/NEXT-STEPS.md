# Prochaines étapes après la base Qbox

1. Installer MariaDB et créer la DB `qbox`
2. Obtenir une clé sur https://portal.cfx.re/servers/subscription
3. Copier `.env.example` → `.env` et remplir
4. `.\scripts\download-artifacts.ps1`
5. `.\scripts\start-server.ps1` → recipe **QBox Framework**
6. `connect 127.0.0.1:30120` dans FiveM (F8)

Ressources utiles ensuite :
- Jobs qbx (police, ambulance, etc.) déjà dans la recipe
- Scripts custom → `server-data/resources/[local]/`
- Docs : https://docs.qbox.re
