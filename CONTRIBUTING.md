# Contribuer

Projet perso d’apprentissage FiveM / Qbox.

## Règles simples

1. Ne jamais committer secrets (`.env`, clés, mots de passe DB)
2. Preferer des resources locales dans `server-data/resources/[local]/`
3. Documenter toute resource custom dans `docs/`
4. Commits : `feat:`, `fix:`, `docs:`, `chore:`

## Workflow

1. Branche feature
2. Tester en local (connect 127.0.0.1)
3. Mettre à jour CHANGELOG si besoin
4. PR ou merge sur `main`
