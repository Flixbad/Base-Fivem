# Acardia Bank

Banque custom Acardia RP V2.

## Fonctionnement

- **Pacific Bank (Vinewood)** : ouverture de comptes + fabrication des cartes
- **Autres banques** : consultation, depot, retrait, virement
- **DAB** : ALT sur le distributeur, insertion de carte, code a 4 chiffres, depot / retrait

## Comptes

| Compte | Plafond | Cartes |
|---|---|---|
| Essentiel | $100,000 | 1 |
| Premium | $500,000 | 2 |
| Prestige | $1,000,000 | 3 |
| Entreprise | $3,000,000 | 20 |

Une carte declaree volee se desactive et libere un slot.

Les tables SQL sont creees automatiquement au demarrage.
